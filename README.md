# MLPiezoV2

Clean machine-learning-focused repository for GeoStudio-driven phreatic surface, factor-of-safety, surrogate modeling, and active learning workflows.

## Scope

This repository is the cleaned V2 line of work extracted from the broader `MLPiezo` history.
It is intended to contain:

- active Python source code
- dataset generation pipelines
- model training pipelines
- workbook-driven GeoStudio update/run workflows
- active learning workflows
- prediction, inverse-design, sensitivity, and visualization tooling
- lightweight technical documentation

It intentionally excludes:

- `.gsz` source model files
- bulky generated datasets
- trained model binaries
- large runtime outputs

## Main Entry Points

- `pipelines/bootstrap_single_model.py`
  - bootstrap a clean per-model workspace from a `.gsz` or `.xml` model
- `pipelines/pipeline_generate_dataset.py`
  - generate GeoStudio-backed training data
- `pipelines/train_models.py`
  - train the ensemble surrogate
- `pipelines/run_hybrid_overnight.py`
  - run dataset generation, training, and active learning in a timed loop
- `pipelines/run_models_from_inputs.py`
  - update prepared model workspaces from an Excel workbook and execute GeoStudio

## Prediction And Analysis Tools

- `scripts/quick_predict.py`
- `scripts/inverse_design.py`
- `scripts/dashboard.py`
- `scripts/sensitivity_analysis.py`
- `scripts/visualize_results.py`

## Preferred Workflow

1. Bootstrap a per-model workspace from a GeoStudio model.
2. Edit the generated per-model `model_config.py`.
3. Generate a dataset.
4. Train the ensemble surrogate.
5. Run prediction, sensitivity, inverse design, or hybrid active learning.

## Environment

Install dependencies with:

```powershell
python -m pip install -r requirements.txt
```

## Notes

- The generic `configs/config.py` is a repository-local default template.
- For real projects, prefer a per-model config generated by the bootstrap pipeline and pass it using `--config-path`.
